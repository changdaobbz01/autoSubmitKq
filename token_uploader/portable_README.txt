考勤 Token 采集器（Windows 便携版）

使用方法：
1. 保持电脑连接湖北省内可访问门户的网络。
2. 双击 AttendanceTokenCollector.exe。
3. 填写管理员提供的云端访问口令并点击“检测”。
4. 输入门户账号、密码，发送并填写短信验证码。
5. 显示“上传完成”后即可关闭程序，本地考勤程序会从云端同步 Token。

安全说明：
- 门户密码只在本机内存中使用，不写入文件，也不会上传云端。
- 云端仅接收考勤账号、Token、有效期和基础身份信息。
- 关闭程序后，访问口令、密码、验证码和待上传 Token 都会清除。
- 压缩包不包含任何账号、访问口令、Token 或运行缓存。

运行要求：
- Windows 10/11 64 位。
- 系统需具备 Microsoft Edge WebView2 Runtime；大多数 Windows 10/11 已自带。
- 必须复制并保留完整文件夹，不能只复制 exe。

排查：
- 门户请求失败：确认当前公网出口位于湖北，并关闭外地代理或 VPN。
- 云端连接失败：检查互联网连接、云端服务地址和访问口令。
- 日志位于程序目录 logs\token-collector.log，日志不会记录密码或 Token。
